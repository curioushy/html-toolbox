# HTML Toolbox

A collection of standalone, single-file HTML tools. Each file is fully self-contained — just open it in a browser, or use the published copies at [curioushy.github.io/html-toolbox](https://curioushy.github.io/html-toolbox/).

## Tools

| Tool | Description |
|------|-------------|
| [folio.html](folio.html) | Folio PDF — work with PDF files in the browser |
| [folio-ocr.html](folio-ocr.html) | Folio-OCR — extract text from scanned PDFs |

## Moved

**Text Compare** and **Text Cleaner** now live in the Evidence Workbook Chrome extension,
[curioushy/evidence-workbook](https://github.com/curioushy/evidence-workbook), under
`theme-binder-extension/tools/`. That is their only master: Word-style track changes, the
.docx redline and all further work are there.

## Features

- **No server** — nothing leaves your machine
- **Portable** — each tool is a single `.html` file, with any libraries it needs beside it
